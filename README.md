# KeigoMate

![KeigoMate Logo](./icon.png)

KeigoMate is a browser extension that helps users transform casual Japanese text into formal business Japanese (keigo) with a single click. Perfect for professionals, students, and anyone looking to polish their communication in Japanese.

## Features

- **AI-Powered Transformation:** Converts casual Japanese to business-level politeness using advanced AI models.
- **Seamless Integration:** Adds a sparkling stars AI button to text input fields on web pages for easy access.
- **Quick and Efficient:** Transforms text in real-time, enhancing productivity without leaving the page.

## Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/jdu211171/keigomate.git
   ```
2. **Load the Extension in Chrome:**
   - Go to `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked" and select the `keigomate` directory

3. **Set Up the Project:**
   - Install dependencies: `npm install`
   - Run the server: `npm run dev`

## Usage

1. **Type Your Message:** Enter your casual Japanese text in any web input field.
2. **Click the AI Button:** Look for the sparkling stars icon on the right of the input field and click it.
3. **Transformed Text:** Your text will be automatically replaced with a formal business Japanese version.
